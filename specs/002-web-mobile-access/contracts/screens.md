# Screen Contract: libread

**Feature**: [spec.md](../spec.md) | **API**: [http-api.md](./http-api.md)

画面が利用者に見せる内容と振る舞いの約束。画面のテスト（research W7）は、この文書の各項目を確かめる。
見た目の細部（色・余白・字の大きさ）は約束に含めない。

## 共通

- 日本語のみ。画面幅 360px の縦向きで、横スクロールなしに館名・状態・開館時刻・書名が読めること（FR-115）。PC のブラウザでも同じ画面を使う。
- 画面は3つ。URL のハッシュで切り替え、画面下部の固定のタブで移動する。

  | ハッシュ | 画面 | User Story |
  |---|---|---|
  | `#/` | 今日 | US1 |
  | `#/books` | 本 | US2 |
  | `#/libraries` | 図書館 | US3 |

- 起動時に `GET /api/session` を呼ぶ。`401` ならログイン画面を表示する。
- どの API でも `401` が返ったら、ログイン画面に切り替える。入力中の内容があれば `sessionStorage` に退避し、ログイン後に戻す（research W12）。
- 通信に失敗した（ネットワークエラー、`5xx`、応答の形が契約と合わない）ときは、`error.message`（なければ「通信に失敗しました」）と「再試行」ボタンを表示する（FR-116）。
  失敗した操作の前に表示していた内容は消さない。ただし検索の結果は、基準時刻を表示したまま残す（下の「今日」を参照）。
- 削除の操作（本・図書館・臨時休館期間）は、ブラウザの確認ダイアログ（`window.confirm`）で「〜を外しますか？」と確かめてから送る（FR-108）。
- 出典表示: カーリル・NDL サーチ・holidays-jp の表示は、API が返す `sources`・`credit` をそのまま表示し、リンクにする。

## ログイン画面

- 「Google でログイン」ボタン。押すと `/auth/login?return=<今の画面>` へ移動する。
- `#/login?error=denied` で開いたときは「ログインできませんでした。libread に登録した Google アカウントでログインしてください」と表示する。
- 利用者データは何も表示しない。

## 今日（`#/`）

### 状態

```text
取得中 --成功--> 結果 --「更新」--> 取得中
取得中 --失敗--> 失敗（前の結果があれば、その基準時刻とともに残す）
取得中 --setupRequired--> 登録の案内
```

- **取得中**: 「所蔵状況を取得しています…」とだけ表示する。途中の結果は表示しない（FR-104）。
  「更新」から取得し直すときは、前の結果を隠して「取得中」にする。
- **結果**: 上から順に、
  1. 基準時刻（例「10月21日(水) 14:05 時点」）と「更新」ボタン。
  2. 「今日読める図書館」: `readable` を API の順のまま番号付きで。館名、`opening.label`、本ごとに書名と `label`。
     空なら「今日読める図書館はありません」。
  3. 「今日は読めない図書館」: `notReadable` を API の順のまま。館名と `opening.label`。`books` があれば本ごとの書名と `label`。
  4. 出典（`sources`）。本ごとのカーリルへのリンク。
- **古い情報**: 結果を表示したまま、基準時刻から30分を超えたら、基準時刻の横に「古い情報」と表示し、
  「更新してください」と案内する（FR-105）。画面を開いたままでも1分ごとに見直す。
- **登録の案内**: `setupRequired` が `libraries` なら「利用図書館が登録されていません」と図書館の画面へのリンク、
  `books` なら「読みかけの本が登録されていません」と本の画面へのリンク。
- 本の絞り込み: 読みかけの本が2冊以上のとき、結果の上に本の選択（「すべての本」＋各書名）を置く。選ぶと `GET /api/check?isbn=` で取得し直す（US1 シナリオ5）。
- 画面を開いたとき、およびほかの画面から戻ったときに取得する。ブラウザのタブが前面に戻ったときは、自動では取得しない（「古い情報」の表示で更新を促す）。

## 本（`#/books`）

- 読みかけの本の一覧: 書名、著者、出版社、メモ、登録日。各本に「メモを編集」と「外す」。
- メモの編集: その場で入力欄に切り替わり、「保存」と「取消」。空にして保存するとメモを消す。
  保存中は「保存」を押せない。成功したら一覧の表示を更新する（US2 シナリオ2）。
- 本を探す: 「書名または ISBN」（必須）、「著者」「出版社」（任意）の入力欄と「探す」。
  - 結果は最大10件。各件に書名・著者・出版社・ISBN と「登録」（登録済みなら「登録済み」と表示して押せない）。
  - `hint` があれば結果の上に表示する。0件なら「見つかりませんでした」と、指定した条件を表示する。
  - 結果の下に NDL サーチのクレジットとライセンスのリンク（`credit`）。
  - 「登録」を押すと、メモの入力欄（任意）を出してから登録する。
- 001 のデータの取り込み: 読みかけの本と利用図書館がどちらも0件のときだけ、一覧の下に「CLI のデータを取り込む」（ファイル選択）を表示する（FR-118）。
  成功したら取り込んだ件数を表示し、一覧を更新する。

## 図書館（`#/libraries`）

- 利用図書館の一覧: 館名、市区町村、開館スケジュールの概要（曜日ごとの時間、祝日の扱い、最終更新日。未入力なら「開館情報未入力」）、臨時休館期間の一覧。
- 各館の操作: 「開館時間を編集」「臨時休館を追加」「外す」。臨時休館期間ごとに「削除」。
- 開館時間の編集: 曜日ごとに「開館／休館」の切り替えと開館・閉館時刻（`<input type="time">`）、祝日の扱い（曜日どおり／休館／時間を指定）。
  初めて入力するときは、すべての曜日が「休館」、祝日は「曜日どおり」の状態から始める。「保存」で `PUT` する。
- 臨時休館の追加: 開始日・終了日（`<input type="date">`）、理由（任意）。開始日が終了日より後なら、送る前に「開始日は終了日以前にしてください」と表示する。
- 図書館を探す: 都道府県（47都道府県の選択。必須）、市区町村、館名（任意）と「探す」。各件に館名・市区町村・住所と「登録」（登録済みなら押せない）。
  結果の下にカーリルへのリンク（`credit`）。

## 設定（図書館の画面の下部）

- 「ログアウト」: `POST /api/session/logout` のあとログイン画面へ。
- 「すべての端末からログアウト」: 確認ダイアログのあと `POST /api/session/revoke-all`、ログイン画面へ（FR-111）。
