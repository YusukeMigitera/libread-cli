# Feature Specification: 今日読める図書館の検索

**Feature Branch**: `001-readable-libraries-today`

**Created**: 2026-10-21

**Status**: Implemented（2026-11-04。tasks.md の T001〜T046 完了）

**Input**: User description: "読みかけの本を登録すると、近隣の図書館のうち今日開館していて館内でその本を読める館が一覧で分かる（コアMVP）"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 今日、続きを読める図書館を知る (Priority: P1)

本を借りずに図書館の館内で読んでいる利用者が検索すると、読みかけの本それぞれについて、
利用する図書館のうち「今日開館していて、その本が館内で手に取れる状態にある館」が館ごとにまとめて表示される。
本を1冊指定して、その本だけを調べることもできる。
利用者はその一覧を見て、今日どの図書館へ行くかを決める。

**Why this priority**: libread の存在理由そのものであり、これだけで
「行ったのに休館だった」「行ったのに本が貸出中だった」という無駄足を防げる。

**Independent Test**: 読みかけの本1冊と利用図書館を用意した状態で検索を実行し、
開館状況と所蔵状況の組み合わせに応じて正しい館だけが「読める」として表示されることを確認する。

**Acceptance Scenarios**:

1. **Given** 利用図書館 A・B・C が登録され、A は今日開館・本が在架、B は今日休館、C は今日開館・本が貸出中,
   **When** その本で検索する,
   **Then** A だけが「読める」として表示され、B は「休館」、C は「貸出中」として理由とともに区別して表示される。
2. **Given** 本が「館内閲覧のみ（貸出禁止）」の資料として在架している開館中の館がある,
   **When** 検索する,
   **Then** その館は「読める」として表示される。
3. **Given** 開館中の館で本が在架している,
   **When** 検索結果を表示する,
   **Then** 各館について今日の閉館時刻、所蔵状況の取得元、取得日時が併記される。
4. **Given** 読みかけの本 P・Q が登録され、開館中の館 A には P と Q、館 B には P のみが在架,
   **When** 本を指定せずに検索する,
   **Then** A（P・Q）、B（P）の順に、館ごとに読める本がまとめて表示される。
5. **Given** どの館でも今日は読めない,
   **When** 検索する,
   **Then** 「今日読める図書館はありません」と表示され、館ごとの理由（休館・貸出中など）が確認できる。

---

### User Story 2 - 読みかけの本を登録する (Priority: P2)

利用者は、館内で読み始めた本を書名や ISBN で探して「読みかけ」として登録する。
登録時に、どこまで読んだか（ページ数など）を任意でメモできる。
登録した本は次回以降、選ぶだけで検索に使える。

**Why this priority**: 毎回本を探し直す手間をなくし、P1 の検索を日常的に使えるものにする。
P1 は読みかけの本を手作業で用意したデータからでも検証できるため、P2 とする。

**Independent Test**: 書名で本を探して登録し、一覧に表示されること、
メモの保存・編集・削除ができることを確認する。

**Acceptance Scenarios**:

1. **Given** 本が未登録,
   **When** 書名で検索して候補から1冊選び登録する,
   **Then** 読みかけの本の一覧にその本が表示される。
2. **Given** 読みかけの本が登録済み,
   **When** 読んだページ数のメモを更新する,
   **Then** 更新後のメモが一覧に表示される。
3. **Given** 本を読み終えた,
   **When** その本を読みかけ一覧から外す,
   **Then** 一覧から消え、検索対象として選べなくなる。

---

### User Story 3 - 利用する図書館を登録する (Priority: P3)

利用者は、普段通える範囲の図書館を選んで登録する。検索は登録した図書館だけを対象に行う。

**Why this priority**: 検索対象を「実際に行ける館」に絞るために必要だが、
利用図書館と開館情報を手作業で用意したデータで P1 は検証できるため、P3 とする。

**Independent Test**: 図書館を追加・削除し、P1 の検索対象がその通りに変わることを確認する。

**Acceptance Scenarios**:

1. **Given** 利用図書館が未登録,
   **When** 都道府県を選んで図書館を名前で探し、2館を追加する,
   **Then** 利用図書館の一覧に2館が表示され、検索対象になる。
2. **Given** 利用図書館が3館登録済み,
   **When** 1館を削除する,
   **Then** 以降の検索ではその館が対象外になる。
3. **Given** 利用図書館 A が登録済み,
   **When** A の通常の開館日・開館時間と、来月の特別整理期間を入力する,
   **Then** 以降の検索では入力内容に従って A の開館・休館が判定される。

---

### Edge Cases

- 図書館の所蔵状況が取得できなかった場合: その館は「状況不明」と表示し、「読める」には含めない。
- 取得した情報が古い（取得から30分を超えた）場合: 「古い情報」と明示し、取得日時を表示する。
  確定した状態とはみなさず、「読める」には含めない。
- 今日は開館日だが、検索時点ですでに閉館時刻を過ぎている場合: 「本日の開館は終了」と表示し、「読める」には含めない。
- 閉館まで残り30分未満の場合: 「読める」に含めつつ、閉館が近いことを明示する。
- 利用者が入力した臨時休館・特別整理期間に今日が含まれる場合: 通常開館日であっても「休館」と表示する。
- 開館情報は利用者入力のため、検索結果には「臨時休館は入力済みの情報のみ反映」である旨を表示する。
- 同じ館に同じ本が複数冊あり、一部が在架・一部が貸出中の場合: 1冊でも在架なら「読める」とする。
- 所蔵状況が「予約中」の場合: 「読める」には含めない。
- 今日は開館日で、検索時点ではまだ開館時刻前の場合: 「読める」に含め、開館時刻を併記する。
- 同じ書名で版や出版社が異なる本: 登録した本と同じ版（ISBN 一致）のみを対象とする。
- 利用図書館が1館も登録されていない場合: 検索の前に図書館の登録を促す。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 利用者は、本を指定せずに検索すると、登録済みのすべての読みかけの本について、
  利用図書館を対象に「今日読めるか」を一度に検索できなければならない。
  本を1冊指定した場合は、その本だけを対象に検索する。
- **FR-002**: システムは、各利用図書館について「今日開館しているか」を、利用者が入力した
  通常の開館日・開館時間と、臨時休館・特別整理期間（FR-016）に基づいて判定しなければならない。
- **FR-003**: システムは、各利用図書館について対象の本の所蔵状況を
  「在架（貸出可）」「在架（館内閲覧のみ）」「貸出中」「予約中」「所蔵なし」「不明」のいずれかに分類しなければならない。
  「予約中」は所蔵状況の取得元が返した値をそのまま表示する。
- **FR-004**: システムは、「今日開館中」または「今日これから開館する（開館時刻前）」で、かつ所蔵状況が
  「在架（貸出可）」または「在架（館内閲覧のみ）」の館のみを「読める」と表示しなければならない。
  開館時刻前の館には開館時刻を併記する。
- **FR-005**: システムは、「読める」以外の館についても、読めない理由（休館・本日終了・開館情報未入力・貸出中・
  予約中・所蔵なし・不明）を館ごとに表示しなければならない。
- **FR-006**: システムは、所蔵状況には取得元と取得日時を、開館情報には「利用者入力」である旨と
  最終更新日を併記しなければならない。
- **FR-007**: システムは、取得に失敗した所蔵状況、または取得から30分を超えた所蔵状況を、
  最新の情報として表示してはならない。
- **FR-008**: 検索結果は図書館ごとにまとめ、各館で読める本を列挙しなければならない。
  館の並びは、読める本の冊数が多い順、同数の場合は今日の閉館時刻が遅い順とする。
- **FR-009**: 利用者は、書名または ISBN で本を探し、読みかけの本として登録・削除できなければならない。
- **FR-010**: 利用者は、読みかけの本ごとに、読んだ位置（ページ数など）を自由記述のメモとして保存・編集できなければならない。
- **FR-011**: 利用者は、日本全国の対応図書館の中から、都道府県を選んだうえで
  図書館名または市区町村名で絞り込んで探し、利用図書館を登録・削除できなければならない。
- **FR-012**: システムは、検索対象を利用者が登録した利用図書館に限定しなければならない。
- **FR-013**: 利用者の読みかけの本・メモ・利用図書館の情報は、次回利用時にも保持されなければならない。
- **FR-014**: 本機能は本人1人だけが使う個人ツールとし、利用者の登録・ログインは設けない。
  読みかけの本・メモ・利用図書館は単一の利用者のものとして扱う。
- **FR-015**: 利用者は、本機能のすべての操作（検索・本の登録・図書館の登録）を、
  PC のターミナルで実行するコマンドから行えなければならない。結果はターミナル上に文字で表示する。
- **FR-016**: 利用者は、利用図書館ごとに、通常の開館日（曜日・祝日の扱い）と曜日ごとの開館・閉館時刻、
  および臨時休館・特別整理期間（開始日〜終了日）を入力・編集・削除できなければならない。
- **FR-017**: 開館情報が未入力の利用図書館は、検索結果で「開館情報未入力」と表示し、「読める」には含めてはならない。

### Key Entities

- **図書館**: 検索対象となる図書館。名称、所在地（市区町村）を持つ。
- **利用図書館**: 利用者が「通える館」として登録した図書館。
- **本**: 書誌情報。書名、著者、出版社、ISBN を持つ。ISBN で同一性を判断する。
- **読みかけの本**: 利用者が読んでいる途中の本。本への参照、読んだ位置のメモ、登録日を持つ。
- **所蔵状況**: ある図書館におけるある本の状態。分類（FR-003）、取得元、取得日時を持つ。
- **開館スケジュール**: 利用者が入力した、ある利用図書館の通常の開館日と曜日ごとの開館・閉館時刻。最終更新日を持つ。
- **臨時休館期間**: 利用者が入力した、ある利用図書館の臨時休館・特別整理期間。開始日、終了日、理由（任意）を持つ。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 利用者は、コマンドを1回実行するだけで「今日どの館で読めるか」を知ることができ、
  入力から結果確認までを30秒以内に完了できる。
- **SC-002**: 利用図書館10館・読みかけの本5冊のすべてを一度に検索しても、検索結果は10秒以内に表示される。
- **SC-003**: 「読める」と表示された館に実際に行ったとき、休館していた・本が手に取れなかったという事例が
  検証期間中の訪問の5%未満である。
- **SC-004**: 状態を確定できない館が「読める」と表示される件数が0件である。
- **SC-005**: 利用者は、読みかけの本の登録を1分以内に完了できる。

## Assumptions

- 対応図書館は、日本全国の公共図書館のうち、複数館の所蔵状況をまとめて提供する外部サービスで
  所蔵状況を取得できる館とする。地域を限定しない。取得できない館は対応図書館として選べない。
- 「近隣」は利用者が自分で登録した利用図書館の集合で表す。現在地からの距離による自動抽出は本機能の範囲外とする。
- 「今日」は利用者のいる地域（日本時間）の暦日とする。
- 所蔵状況の鮮度の許容範囲は30分とする（Constitution 原則 IV に基づく既定値）。
- 開館情報の自動取得は範囲外とする。開館情報の正しさは利用者の入力内容に依存する。
- 本の取り置き・予約・貸出の手続きは範囲外とする（libread は借りずに館内で読む人のためのサービス）。
- 図書館内のどの棚にあるかの案内は範囲外とする。
- 読んだ位置のメモは利用者のための記録であり、図書館側には送信しない。
- 利用者は本人1人のみ（FR-014）。複数利用者への対応は範囲外とする。
- 利用はPCのターミナルから行う（FR-015）。スマートフォン向けの画面や通知は範囲外とする。

## Clarifications

### Session 2026-10-21

- Q: 本人1人だけが使う個人ツールか、複数利用者のサービスか？ → A: 本人1人だけが使う個人ツール（登録・ログインなし）
- Q: libread を主にどこでどう使うか？ → A: PC のターミナルで実行するコマンドラインツール
- Q: libread はどの範囲の図書館に対応する必要があるか？ → A: 日本全国の公共図書館（複数館の所蔵を集約する外部サービスを利用）
- Q: 各館の開館日・開館時間・臨時休館の情報はどこから得るか？ → A: 利用者が館ごとに手入力し、変更時も利用者が更新する
- Q: 検索は本を1冊ずつか、読みかけの本すべてを一度にか？ → A: 既定ではすべてを一度に検索し、1冊を指定することもできる
