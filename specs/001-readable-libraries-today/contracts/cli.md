# CLI Contract: libread

**Feature**: [spec.md](../spec.md) | **Data Model**: [data-model.md](../data-model.md)

## 共通

- 出力は標準出力に日本語で書く。エラーは標準エラー出力に書く。
- 終了コード:
  - `0` 成功。「今日読める図書館なし」や、一部の館が「不明」の場合も成功とする。
  - `1` 実行時エラー。例: データファイルの読み書き失敗、外部サービスに全く接続できない。
  - `2` 使い方の誤り。例: 引数不足、該当なし、候補が複数ある。
- 使い方の表示: 次の場合は、使い方を標準出力に書いて終了コード `0` で終わる。
  - `libread help`・`-h`・`--help`: すべてのコマンドの概要。
  - `libread book|lib|lib closure` に続けて `help`・`-h`・`--help`（例: `libread lib closure --help`）: その階層の使い方。
  - サブコマンドや `check` の引数に `-h`・`--help` を含める（例: `libread book find --help`、`libread check -h`）: そのコマンドの使い方。
    `check` は引数に `<本>` を取るので、`libread check help` は「help」を書名とする本の指定として扱う。

  使い方の誤りとして使い方を出すときは、標準エラー出力に書いて終了コード `2`。
- 環境変数:
  - `LIBREAD_CALIL_APPKEY`: カーリルのアプリケーションキー。`check`、`lib find`、`lib add` で必須。
    未設定なら終了コード `1` で、設定方法を案内する。
  - `LIBREAD_DATA_DIR`: データファイルの置き場所を変える（任意）。
  - `LIBREAD_CACHE_DIR`: キャッシュの置き場所を変える（任意）。
- `<本>` の指定方法: ISBN（10桁・13桁、ハイフン可）、または書名の部分一致。
  部分一致で候補が複数ある場合は、候補を一覧表示して終了コード `2`。
- `<図書館>` の指定方法: `SystemID:LibKey`、または図書館名の部分一致。複数一致の扱いは `<本>` と同じ。

## コマンド一覧

| コマンド | 機能 | 対応 FR |
|---|---|---|
| `libread [check [<本>]]` | 今日読める図書館を検索する。引数なしなら読みかけの本すべてが対象 | FR-001〜008, 012, 017 |
| `libread book find <書名\|ISBN> [--author <著者>] [--publisher <出版社>]` | 書誌を検索して候補を表示する（最大10件） | FR-009 |
| `libread book add <ISBN> [--note <テキスト>]` | 読みかけの本として登録する | FR-009, 010 |
| `libread book list` | 読みかけの本とメモを一覧表示する | FR-009 |
| `libread book note <本> <テキスト>` | メモを上書きする（空文字で消去） | FR-010 |
| `libread book rm <本>` | 読みかけの本から外す | FR-009 |
| `libread lib find --pref <都道府県> [--city <市区町村>] [--name <部分一致>]` | 対応図書館を検索する | FR-011 |
| `libread lib add <SystemID:LibKey>` | 利用図書館として登録する | FR-011 |
| `libread lib list` | 利用図書館と開館スケジュールの概要を表示する | FR-011, 016 |
| `libread lib rm <図書館>` | 利用図書館から外す | FR-011 |
| `libread lib hours <図書館> [--sun 〜 --sat <時間>] [--holiday <祝日>]` | 開館スケジュールを設定する | FR-016 |
| `libread lib closure add <図書館> <開始日> <終了日> [--reason <テキスト>]` | 臨時休館期間を追加する | FR-016 |
| `libread lib closure list <図書館>` | 臨時休館期間を番号付きで表示する | FR-016 |
| `libread lib closure rm <図書館> <番号>` | 臨時休館期間を削除する | FR-016 |

### `lib hours` の値

- `<時間>`: `HH:MM-HH:MM` または `closed`。指定しなかった曜日は現在の値を変えない。
  スケジュールがまだ無い場合、指定しなかった曜日は「休館」になる。
  そのため、初めて設定するときは曜日を1つ以上指定する必要がある（`--holiday` だけなら終了コード `2`）。
- `<祝日>`: `same`（曜日どおり） / `closed` / `HH:MM-HH:MM`。初めて設定するときの既定は `same`。
- 実行すると最終更新日が今日の日付になる。

### `book find` / `book add` の補足

- 書誌は国立国会図書館サーチの蔵書（`dpid=iss-ndl-opac`）から探す（research.md R3）。
- 書名検索の候補の並び（research.md R3）: NDL サーチは書名の読みの五十音順で返し、収録作品名にも一致する。
  そのため1回の要求で最大20件を取得し、書名が検索語と完全一致する本 → 検索語で始まる本 → その他の順に並べ替えて、上位10件を表示する。
  同じ順位の本は NDL サーチが返した順のままにする。ISBN で探すときは並べ替えない。
- `--author` と `--publisher` は、NDL サーチの `creator` と `publisher` にそのまま渡して絞り込む。
- 見出しと「見つかりませんでした」のメッセージには、書名とあわせて指定した絞り込み条件を `「<書名>」（著者: <著者>、出版社: <出版社>）` の形で書く。
  指定しなかった条件は省く。
- 一致した件数が表示した件数より多いとき（取得しきれなかった、または上位10件に入らなかった本があるとき）は、
  見出しに `（<一致件数>件中<表示件数>件を表示）` と書き、絞り込み方と ISBN での検索を案内する1行を出す。
  すべて表示できたときは、見出しは `（<件数>件）` とし、案内は出さない。
- 一致はあるのに、取得した記録に ISBN のある本が1件もないとき（古い全集などが先に並ぶとき）も、
  `<一致件数>件の一致がありますが、取得した中に ISBN のある本がありませんでした。` に続けて同じ案内を出し、終了コード `2` にする。

  ```text
  「吾輩は猫である」の検索結果（345件中10件を表示）
  1. 9784895283694 『赤い実 : ほか』 井上, 靖, 1907-1991、三木, 卓, 1935-2023、安岡, 章太郎, 1920-2013、直野, 敦, 1929- / 光村図書出版
  ...

  表示しきれていない本があります。見つからないときは --author <著者> や --publisher <出版社> で絞り込むか、ISBN で探してください
  登録するには: libread book add <ISBN> [--note <テキスト>]

  書誌情報: 国立国会図書館サーチ API から取得した「国立国会図書館蔵書」（国立国会図書館が運営）のデータを利用しています（https://ndlsearch.ndl.go.jp/）
  ライセンス: クリエイティブ・コモンズ 表示 4.0 国際（https://creativecommons.org/licenses/by/4.0/legalcode.ja）
  ```

- 出典表示（NDL サーチの利用条件, research.md R10）: `book find` と `book add` の出力の末尾に、次の2行を必ず表示する。
  `libread help` の末尾にも同じ2行を表示する。
  NDL サーチの API を使っていることに加え、`iss-ndl-opac` のメタデータは CC BY 4.0 なので、
  データプロバイダ（国立国会図書館蔵書）とデータ提供機関（国立国会図書館）の名前と、ライセンスへのリンクを示す。

  ```text
  書誌情報: 国立国会図書館サーチ API から取得した「国立国会図書館蔵書」（国立国会図書館が運営）のデータを利用しています（https://ndlsearch.ndl.go.jp/）
  ライセンス: クリエイティブ・コモンズ 表示 4.0 国際（https://creativecommons.org/licenses/by/4.0/legalcode.ja）
  ```

### `lib find` の補足

- spec FR-011 のとおり、都道府県を選んでから探す。カーリルの図書館検索は都道府県の指定が必須なので、`--pref` を必須とする。
  市区町村は `--city` でカーリルに渡す。図書館名（`--name`）での絞り込みは libread 側で行う。
- 表示する列: `SystemID:LibKey`、正式名、市区町村、住所。
- カーリルの応答に `systemid` か `libkey` の欠けた館があれば、その館だけを表示しない（登録も所蔵確認もできないため）。
- 図書館名を表示するので、カーリルの利用条件（research.md R1）に従って出力の末尾にカーリルへのリンクを1行表示する。

  ```text
  「東京都 世田谷区」で「中央」を含む図書館（2館）
  1. Tokyo_Setagaya:中央図書館  世田谷区立中央図書館  世田谷区  東京都世田谷区弦巻3-16-8
  2. Univ_Kokushikan:中央  国士舘大学中央図書館  世田谷区  東京都世田谷区世田谷4-28-1

  登録するには: libread lib add <SystemID:LibKey>

  図書館情報: カーリル（https://calil.jp/）
  ```

### `lib add` の補足

- アプリケーションキーがなければ、登録済みかどうかにかかわらず終了コード `1` で設定方法を案内する。
- 指定した `SystemID:LibKey` が実在するかを、カーリルの図書館検索（`systemid` を指定、1リクエスト）で確かめる。
  見つからなければ（存在しない `systemid` にはカーリルが空の配列を返す）終了コード `2`。登録する名前・都道府県・市区町村はカーリルの値を使う。
- すでに登録済みの図書館なら、カーリルに問い合わせずに終了コード `2`。

### `lib hours` / `lib closure` の補足

- `lib hours` には `--sun`〜`--sat` と `--holiday` のどれか1つ以上が必要。何も指定しなければ終了コード `2`。
- `lib closure add` の日付は `YYYY-MM-DD`。開始日が終了日より後なら終了コード `2`。
  開始日・終了日・理由がすべて同じ期間がすでにあれば、終了コード `2`。期間が重なるだけなら追加できる。
- 臨時休館期間は開始日の順に並べる（`data.json` を手で編集して順が崩れていても、読み込むときに並べ直す）。
  `lib closure list` の番号はこの順で、`lib closure rm` はこの番号で指定する。

## `check` の出力例

```text
2026-10-21(水) 14:05 時点

■ 今日読める図書館
1. 世田谷区立中央図書館  開館中 〜19:00
   - 『本のタイトルP』 在架（貸出可）
   - 『本のタイトルQ』 在架（館内閲覧のみ）
2. 世田谷区立奥沢図書館  開館前 15:00〜20:00
   - 『本のタイトルP』 在架（館内閲覧のみ）
   - 『本のタイトルQ』 予約中
3. 世田谷区立経堂図書館  開館中 〜14:30（閉館まで30分未満）
   - 『本のタイトルP』 在架（貸出可）
   - 『本のタイトルQ』 貸出中

■ 今日は読めない図書館
- 世田谷区立梅丘図書館  休館（特別整理期間 2026-10-20〜2026-10-24）
- 世田谷区立烏山図書館  開館中 〜19:00
   - 『本のタイトルP』 不明（蔵書あり／貸出状況不明）
   - 『本のタイトルQ』 所蔵なし
- 世田谷区立深沢図書館  開館情報未入力

所蔵情報: カーリル 14:05 取得（30分以内の取得結果を使用）
  『本のタイトルP』 https://calil.jp/book/9784000000001
  『本のタイトルQ』 https://calil.jp/book/9784000000002
開館情報: 利用者入力（最終更新 中央図書館 2026-10-01 / 経堂図書館 2026-10-01 / 奥沢図書館 2026-10-05 / 梅丘図書館 2026-09-15 / 烏山図書館 2026-10-10）
※ 臨時休館は入力済みの情報のみ反映しています
```

- 開館時刻前の館は「読める」側に含め、`開館前 HH:MM〜HH:MM` と開館時刻を併記する（FR-004）。
- 所蔵状況「予約中」は、カーリルが返した値をそのまま表示する（FR-003）。
- 読める図書館が1館もないときは、「■ 今日読める図書館」の下に「今日読める図書館はありません」と表示する。
- 所蔵の取得日時が本・システムによって違うときは、本ごとに `（HH:MM 取得）` を付ける。
- 古いキャッシュしか使えなかった本は `不明（古い情報: HH:MM 取得）` と表示する。
- 利用図書館が未登録なら、`libread lib find` で登録するよう案内して終了コード `2`。
- 読みかけの本が未登録なら、`libread book find` で登録するよう案内して終了コード `2`。
