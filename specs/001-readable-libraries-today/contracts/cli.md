# CLI Contract: libread

**Feature**: [spec.md](../spec.md) | **Data Model**: [data-model.md](../data-model.md)

## 共通

- 出力は標準出力に日本語で書く。エラーは標準エラー出力に書く。
- 終了コード:
  - `0` 成功。「今日読める図書館なし」や、一部の館が「不明」の場合も成功とする。
  - `1` 実行時エラー。例: データファイルの読み書き失敗、外部サービスに全く接続できない。
  - `2` 使い方の誤り。例: 引数不足、該当なし、候補が複数ある。
- 環境変数:
  - `LIBREAD_CALIL_APPKEY`: カーリルのアプリケーションキー。`check` と `lib find` で必須。
    未設定なら終了コード `1` で、設定方法を案内する。
  - `LIBREAD_DATA_DIR`: データファイルの置き場所を変える（任意）。
  - `LIBREAD_CACHE_DIR`: キャッシュの置き場所を変える（任意）。
- `<本>` の指定方法: ISBN（10桁・13桁、ハイフン可）、または書名の部分一致。
  部分一致で候補が複数ある場合は、候補を一覧表示して終了コード `2`。
- `<図書館>` の指定方法: `SystemID:LibKey`、または図書館名の部分一致。複数一致の扱いは `<本>` と同じ。

## コマンド一覧

| コマンド | 機能 | 対応 FR |
|---|---|---|
| `libread [check [<本>]]` | 今日読める図書館を検索する。引数なしなら読みかけの本すべてが対象 | FR-001〜008, 012, 017 |
| `libread book find <書名\|ISBN>` | 書誌を検索して候補を表示する（最大10件） | FR-009 |
| `libread book add <ISBN> [--note <テキスト>]` | 読みかけの本として登録する | FR-009, 010 |
| `libread book list` | 読みかけの本とメモを一覧表示する | FR-009 |
| `libread book note <本> <テキスト>` | メモを上書きする（空文字で消去） | FR-010 |
| `libread book rm <本>` | 読みかけの本から外す | FR-009 |
| `libread lib find --pref <都道府県> [--city <市区町村>] [--name <部分一致>]` | 対応図書館を検索する | FR-011 |
| `libread lib add <SystemID:LibKey>` | 利用図書館として登録する | FR-011 |
| `libread lib list` | 利用図書館と開館スケジュールの概要を表示する | FR-011, 016 |
| `libread lib rm <図書館>` | 利用図書館から外す | FR-011 |
| `libread lib hours <図書館> [--sun 〜 --sat <時間>] [--holiday <祝日>]` | 開館スケジュールを設定する | FR-016 |
| `libread lib closure add <図書館> <開始日> <終了日> [--reason <テキスト>]` | 臨時休館期間を追加する | FR-016 |
| `libread lib closure list <図書館>` | 臨時休館期間を番号付きで表示する | FR-016 |
| `libread lib closure rm <図書館> <番号>` | 臨時休館期間を削除する | FR-016 |

### `lib hours` の値

- `<時間>`: `HH:MM-HH:MM` または `closed`。指定しなかった曜日は現在の値を変えない。
  スケジュールがまだ無い場合、指定しなかった曜日は「休館」になる。
- `<祝日>`: `same`（曜日どおり） / `closed` / `HH:MM-HH:MM`。初めて設定するときの既定は `same`。
- 実行すると最終更新日が今日の日付になる。

### `book find` / `book add` の補足

- 書誌は国立国会図書館サーチの蔵書（`dpid=iss-ndl-opac`）から探す（research.md R3）。
- 出典表示（NDL サーチの利用条件, research.md R10）: `book find` と `book add` の出力の末尾に、次の1行を必ず表示する。
  `libread help` の末尾にも同じ1行を表示する。

  ```text
  書誌情報: 国立国会図書館サーチ API を利用しています（https://ndlsearch.ndl.go.jp/）
  ```

### `lib find` の補足

- spec FR-011 のとおり、都道府県を選んでから探す。カーリルの図書館検索は都道府県の指定が必須なので、`--pref` を必須とする。
  市区町村は `--city` でカーリルに渡す。図書館名（`--name`）での絞り込みは libread 側で行う。
- 表示する列: `SystemID:LibKey`、正式名、市区町村、住所。

## `check` の出力例

```text
2026-10-21(水) 14:05 時点

■ 今日読める図書館
1. 世田谷区立中央図書館  開館中 〜19:00
   - 『本のタイトルP』 在架（貸出可）
   - 『本のタイトルQ』 在架（館内閲覧のみ）
2. 世田谷区立奥沢図書館  開館前 15:00〜20:00
   - 『本のタイトルP』 在架（館内閲覧のみ）
   - 『本のタイトルQ』 予約中
3. 世田谷区立経堂図書館  開館中 〜14:30（閉館まで30分未満）
   - 『本のタイトルP』 在架（貸出可）
   - 『本のタイトルQ』 貸出中

■ 今日は読めない図書館
- 世田谷区立梅丘図書館  休館（特別整理期間 2026-10-20〜2026-10-24）
- 世田谷区立烏山図書館  開館中 〜19:00
   - 『本のタイトルP』 不明（蔵書あり／貸出状況不明）
   - 『本のタイトルQ』 所蔵なし
- 世田谷区立深沢図書館  開館情報未入力

所蔵情報: カーリル 14:05 取得（30分以内の取得結果を使用）
  『本のタイトルP』 https://calil.jp/book/9784000000001
  『本のタイトルQ』 https://calil.jp/book/9784000000002
開館情報: 利用者入力（最終更新 中央図書館 2026-10-01 / 経堂図書館 2026-10-01 / 奥沢図書館 2026-10-05 / 梅丘図書館 2026-09-15 / 烏山図書館 2026-10-10）
※ 臨時休館は入力済みの情報のみ反映しています
```

- 開館時刻前の館は「読める」側に含め、`開館前 HH:MM〜HH:MM` と開館時刻を併記する（FR-004）。
- 所蔵状況「予約中」は、カーリルが返した値をそのまま表示する（FR-003）。
- 読める図書館が1館もないときは、「■ 今日読める図書館」の下に「今日読める図書館はありません」と表示する。
- 所蔵の取得日時が本・システムによって違うときは、本ごとに `（HH:MM 取得）` を付ける。
- 古いキャッシュしか使えなかった本は `不明（古い情報: HH:MM 取得）` と表示する。
- 利用図書館が未登録なら、`libread lib find` で登録するよう案内して終了コード `2`。
- 読みかけの本が未登録なら、`libread book find` で登録するよう案内して終了コード `2`。
